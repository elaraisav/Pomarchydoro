# Security policy

## Supported versions

Only the latest version on `main` is supported.

## Reporting a vulnerability

Please don't report security vulnerabilities in public issues. Use GitHub's [private vulnerability reporting](https://github.com/elaraisav/Pomarchydoro/security/advisories/new).

Include a description of the problem, steps to reproduce it, and the plugin version and Omarchy version you tested with. Reports are handled as time allows.
